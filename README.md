# js_game_for_kids

Authors: Hung-Fu Chang, Ph.D. and Wenhui Zhu, Ph.D.

The current 23-chapter edition is in [Quarto_Doc](Quarto_Doc/README.md).

**Chapters 16–23 require a local HTTP server for all six Game Lab projects.** The earlier one-file games can open directly. For the simplest setup, install Node.js LTS once from [the official download page](https://nodejs.org/en/download), extract the book folder, then double-click the Windows or Mac launcher inside `Quarto_Doc`. No `npm install` is needed.

See the [step-by-step installation and game requirements guide](Quarto_Doc/appendices/e-game-lab.qmd), or open `Quarto_Doc/preview.html` and choose **Your Game Lab**.
