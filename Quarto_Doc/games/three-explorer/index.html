Robot Island Explorer

Local HTTP server required

Start start-game-lab.bat (Windows) or start-game-lab.command (Mac) in the Quarto_Doc folder, then choose this project at http://127.0.0.1:8000/games/. Opening this HTML file directly will not start the game. Internet is needed for 3D libraries by default. Installation and troubleshooting.

Explore a 3D island and collect four crystals.

Loading Three.js and assets; an internet connection is needed for the libraries.

WASD or arrow keys move; drag to orbit; scroll to zoom.

Editable source: three-explorer/main.js. Assets: games/assets/.
