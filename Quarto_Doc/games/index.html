Your 2D + 3D Game Lab

Six hands-on projects accompany Chapters 15-22. Keep the whole games folder together.

For Chapters 2–4, compare the early scene examples: Structure → Style → Behavior planning.

All six projects below require a local HTTP server

One-time setup: install Node.js LTS from the official download page. Then double-click start-game-lab.bat (Windows) or start-game-lab.command (Mac) in the Quarto_Doc folder. Keep its window open and play at http://127.0.0.1:8000/games/.

Step-by-step Windows/Mac installation and troubleshooting. No npm install is needed. The two 2D projects run offline through the server; the four 3D projects need internet for library downloads by default. The earlier Chapters 2–14 one-file games can open directly.
