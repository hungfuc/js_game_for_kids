# Breakout Practice

Open `index.html` and use the left and right arrow keys to catch the ball. The demonstration pages pause animation and make one or three controlled brick collisions to show how the brick array and score change.

## Practice with the book’s development flow

**Build the scene structure → Style the scene → Program game behavior.**

1. **Build the scene structure:** Identify the page groups, controls, play area, objects, and starting data this example needs.
2. **Style the scene:** Inspect CSS or canvas drawing. Check that objects, controls, and feedback are easy to recognize.
3. **Program game behavior:** Trace input, state changes, and game rules. Predict one action, run it, and compare the result.

Reuse stages that already support your exercise. For a static or paused demonstration, describe the planned action or compare the shown states; add live behavior only when the exercise calls for it. Folder numbering includes earlier example sequences; follow the chapter titles in the current Quarto book.
