# Chapter 5 Catch the Star

Open `index.html` directly in a browser. The star moves every second, and clicking it adds a point and moves it immediately. The screenshot demonstration pages use fixed random positions: `demo-start.html` pauses the timer, `demo-after-timer.html` invokes one timer callback, and `demo-after-click.html` invokes one timer callback and one click. These controls make the three book images reproducible; the runnable `index.html` keeps its normal one-second timer.

## Practice with the book’s development flow

**Build the scene structure → Style the scene → Program game behavior.**

1. **Build the scene structure:** Identify the page groups, controls, play area, objects, and starting data this example needs.
2. **Style the scene:** Inspect CSS or canvas drawing. Check that objects, controls, and feedback are easy to recognize.
3. **Program game behavior:** Trace input, state changes, and game rules. Predict one action, run it, and compare the result.

Reuse stages that already support your exercise. For a static or paused demonstration, describe the planned action or compare the shown states; add live behavior only when the exercise calls for it.
