# Chapter 3 Monster Clicker starter

Open `starter.html` for the current Chapter 3 example. It works directly in a browser without a server.

Follow **Build the scene structure → Style the scene → Program game behavior**:

1. **Build the scene structure:** identify the title, monster button, message, score, and main card in the body.
2. **Style the scene:** identify the CSS rules in the head. Change a visual value and check the page.
3. **Program game behavior:** plan a hit that raises the score and changes the message. Inspect the starting score, lives, treasures, and player data in the browser console. This starter prepares memory; Chapter 4 adds the click action. Clicking here does not yet change the page.

The CSS appears before the body because it belongs in the HTML head. The development order remains structure, style, then behaviors.
