# Optional Game Maker HQ reference examples

Follow **Build the scene structure → Style the scene → Program game behavior**.

1. **Build the scene structure:** open `plain.html` and identify the title, gem preview, missions, and player controls.
2. **Style the scene:** open `index.html` to see the same scene with `styles.css`. Change one CSS value, save, and refresh to check the result.
3. **Program game behavior:** describe the future action that reads the nickname and choices to prepare a game. The page has no JavaScript game operations yet; native typing, selection, and checkbox interaction still work.

`index.html` and `styles.css` match Appendix F's complete Game Maker HQ examples. The local `gem.svg` keeps both pages offline. Open them directly in a browser; no server is needed.

`monster-page/index.html` is Appendix F's static Monster Clicker rehearsal. Apply the same three steps: locate the monster/message/score, inspect their style, then plan the hit action. Chapter 5 supplies data before Chapter 6 connects that action.

For the current Chapters 2–4 sequence, use `../foundations/structure/`, `../foundations/style/`, and `../foundations/behavior/`.
