# Static Monster Clicker rehearsal

Follow **Build the scene structure → Style the scene → Program game behavior**.

1. Read `index.html`: locate the title, monster, message, score, and their IDs.
2. Read `styles.css`: locate the card, button, spacing, colors, and focus ring. Change one visual value and refresh.
3. Plan the hit action: add one to the score and change the message. This page does not implement the action yet. Chapter 5 prepares its data; Chapter 6 connects clicks.

Open `index.html` directly in a browser. This is the runnable copy of Appendix F's rehearsal example.
