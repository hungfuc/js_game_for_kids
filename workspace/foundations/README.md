# Structure → Style → Behavior: Chapters 2–4

Open each `index.html` directly in a browser; no server is required.

| Folder | Chapter | What to check |
| --- | --- | --- |
| `structure/` | 2 | Title, instructions, arena, monster, score, message, and reading order. |
| `style/` | 3 | The same scene with readable CSS, spacing, hover, and keyboard focus. |
| `behavior/` | 4 | The styled scene plus labeled nickname, mode, sound, and Restart controls. |

The Chapter 4 copy includes the practice additions so you can inspect them together. Native typing, menu selection, and checkbox toggling work. Monster hits and Restart have no game handlers yet: predict and simulate their rules on paper. Chapter 5 prepares memory; Chapter 6 connects game actions to JavaScript.

Practice by changing one part, saving, refreshing, and comparing the result with your prediction. `gem.svg` is supplied in the styled folders for the optional image practice. Full HTML/CSS lookup tables and the Game Maker HQ example are in Appendix F.
